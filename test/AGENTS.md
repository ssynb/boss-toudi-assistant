# 测试边界

- 批次规则在 State + Executor 接缝验证；站点替身只模拟外部页面结果，不替代审批与账本。
- HTTP 验证包含敏感 GET 与事件流的来源限制，不能只测写接口。
- 模型测试运行真正的 Codex 二进制，由本地 Responses 服务回放模型输出；它证明协议与受限工具，不证明真实账号可用。
- 浏览器测试运行真正 CloakBrowser + agent-browser，核实可执行路径并完成本地快照/填入/点击；不得换成普通 Chrome 或真实 HR 目标。未取得下载许可时不能替用户自动设置确认变量，也不能跳过该验收假装通过。
- 新回归测试先观察真实预期失败再修复；已锁定的验收测试不随实现改卷。
