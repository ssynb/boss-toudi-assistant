# 后端结构与验收边界

## 进程与数据流

一套 Node 本地 HTTP 服务负责状态和编排，静态 UI 放在 `public/`。Codex app-server、agent-browser 及 Chrome 是受控子进程，不存在 Python、容器或远程控制平面。TypeScript 直接由 Node 执行；最低版本 24.11.0 已在 macOS 实测可用原生 TS 与 node:sqlite（该版本 sqlite 仍会输出实验警告）。

发现流程：用户确认的简历正文与条件 → Codex → 应用的搜索/读详情工具 → 草案。工具按完整操作串行，避免两个搜索互相切换页面。模型提供的 jobId 必须来自本轮观察，不能编造外部目标。

执行流程：批准当前批次版本 → 确定性执行器 → 浏览器适配器。模型不参与执行。版本在同一数据库内跨批次单调递增，替换草案不会复用旧版本，旧页面不能批准新目标。SQLite 使用同步事务和独占连接；同一数据目录不能被两个服务同时处理。应用禁止发现与执行并行，禁止执行中修改、发现中改稿。

## 职责

- `app.ts`：生命周期、互斥编排、事件通知。
- `state.ts`：资料、批次版本、批准、跨批次联系账本与崩溃恢复。
- `executor.ts`：逐步骤执行与暂停，任何对外动作前先记录 inflight。
- `codex.ts` / `discovery.ts`：stdio RPC、登录、拒绝越权审批、根线程工具权限、发现草案。
- `browser.ts` / `boss.ts`：跨平台子进程调用与 BOSS 页面读取/操作。
- `resume.ts`：本地文件存储与文本提取。pdf/docx 不解析，因此不需要 PDF/ZIP/Office 解析依赖。
- `server.ts`：HTTP、SSE、静态托管和本机来源校验。

接口形状、错误与语义只维护于 `src/contracts.ts`。

## 本机隔离

数据目录下：`state.sqlite` 存业务事实；`resume/` 存按哈希命名的文件；`browser-profile/` 存专属浏览器 profile；`codex-home/` 由 Codex 自行存登录；`codex-user-home/` 隔离用户技能；`codex-work/` 是独立工作目录。

Codex 不复用用户其他客户端的目录，避免继承 MCP server、hooks 与 AGENTS。子进程不继承 API key、NODE_OPTIONS 等隐式配置。agent-browser 使用项目显式配置而非用户默认配置，不启用插件。模型 shell 与浏览器工具关闭；文件修改、命令和权限审批均拒绝。

HTTP 只接受实际监听端口对应的回环 Host；有 Origin 时必须同源，跨站 Fetch Metadata 被拒；所有 API 包括读取和事件流均要求专用头，无 CORS。CSP 禁止内联脚本和外部脚本，允许内联样式；设计师应把 JS 写到 `public/` 的独立模块。

## 真实站点限制

当前自动化测试证明规则和协议，不证明 BOSS 当前 DOM 或默认招呼时序。未登录只读访问观察到安全验证页，未绕过或由代理完成。

- 登录后的账号标识、岗位卡、职位详情、当前会话公司与消息区域选择器尚需本人登录验证。无法正向识别就停止，不能将空页面判成登录成功或没有本方消息。
- 在批准后的目标岗位页读取招聘者身份；进入聊天页后及发送前，同时核对岗位链接、招聘者链接、公司和消息区域。同公司其他岗位或招聘者也不能发送。绑定仅存在于当前进程，重启后缺少绑定的已联系目标会停止，不以公司名重建身份或重新联系。
- 招呼和附件证据只读取当前会话的本方消息区域。附件从独立文件名字段提取，发送前必须只有一个候选且完整文件名精确相等；发送后必须出现新增的同名附件字段，正文子串不能作为证据。
- 未验证「发简历」按钮是否直接发送，因此不会自动点击入口。只有已经显示附件名的确认对话框才可能发送；招聘者链接与附件 `data-file-name` 字段仍需在真实页面验证，缺失就停止，不能退回公司名或整段正文模糊匹配。完整附件流程尚未完成现场验收。
- 发送后没有对应消息证据就记录 unknown；浏览器命令中途抛错同样不能当作未发送。

## 验证

`npm run check` 包含规则、HTTP、真实 Codex 进程连接假模型、真实 Chrome 本地页。Windows CI 与 macOS CI 运行完整测试，而非仅类型检查。当前 Windows 配置尚未推送触发，因此没有 Windows 成功证据。

尚需：本人在应用里登录 Codex 与 BOSS；只读确认岗位与会话结构；另行授权明确的测试目标才能验收发送。不能因假模型测试通过而宣布真实账号/站点端到端成功。
