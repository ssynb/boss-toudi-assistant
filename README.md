# boss 投递助手

macOS / Windows 本地项目：用自己的Codex账号搜索BOSS直聘岗位，按对话授权边找边投，或先存草稿再确认发送。

工作台通过对话启动调研与投递；真实账号可用性取决于登录状态、平台额度和页面变化。

## 安装与启动

需要 Node.js **24.11.0 或更高版本**，推荐当前 Node 24 LTS。下载：[nodejs.org](https://nodejs.org/)。不需要 Docker、Python 或全局安装 Codex。

```sh
npm ci
npm run setup
npm start
```

打开终端显示的地址（默认 `http://127.0.0.1:4318`）。也可以把下面这句话复制给自己的 Codex：

> 请从 https://github.com/ssynb/boss-toudi-assistant 获取源码，阅读 AGENTS.md，检查 Node.js 至少为 24.11.0（不满足时先指导我从 Node 官方渠道安装），然后执行 npm ci 和 npm run setup；若缺少 CloakBrowser，先让我确认官方二进制许可，同意后按 README 安装。最后 npm start 并告诉我本地访问地址；登录和验证码由我本人完成，不联系任何 HR。

`setup` 检查 Node、Codex、agent-browser、CloakBrowser 和数据目录。**唯一浏览器是 CloakBrowser**，agent-browser 只负责遥控；不探测、安装或回退到普通 Chrome，也不支持自定义可执行文件路径。

### CloakBrowser 安装与许可

固定使用官方 npm wrapper `cloakbrowser@0.6.3`。wrapper 是 MIT，**浏览器二进制是单独的专有许可**，不能把 MIT 当作二进制许可。请本人先阅读 [Binary License v1.3](https://github.com/CloakHQ/CloakBrowser/blob/main/BINARY-LICENSE.md)：dependency listing 允许终端用户从官方渠道直接下载；禁止二进制打包、再分发；latest major 的使用受厂商订阅要求约束。

本实现只接入不需要 key 的免费旧版；不获取 key、不付款、不使用用户全局 bbu 或 CloakBrowser 个人许可证。已有官方免费缓存可直接检查使用；缺失时 `npm run setup` 会明确失败，不自行下载或接受许可。

**仅当本人审阅并同意许可后**，手动运行：

macOS：
```sh
BOSS_CLOAK_LICENSE_ACCEPTED=1.3 npm run setup -- --install-cloak
```

Windows PowerShell：
```powershell
$env:BOSS_CLOAK_LICENSE_ACCEPTED = '1.3'
npm run setup -- --install-cloak
Remove-Item Env:BOSS_CLOAK_LICENSE_ACCEPTED
```

只有本人已明确同意上述许可后，才可由代理执行相应的安装和 CI 配置。官方 wrapper 负责下载、签名与归档校验；项目不打包二进制，也不上传到 CI 缓存或制品。安装后重新运行检查并启动。

## 使用流程

界面左侧切换三页：**对话**（默认，所有任务从这里开始）、**个人信息**（简历、固定招呼语与可选求职偏好）、**投递记录**（每个岗位的状态；招呼语默认收起，只在未确认或未发生时可展开核查）。

1. 在本应用登录 Codex（ChatGPT账号），在个人信息页保存简历和固定招呼语。固定招呼去首尾空白后最多200字，与资料一起保存；未设置时不能开始找岗或投递。投递逐字使用该文本，AI不再逐岗位撰写。txt/md 自动提取正文；pdf/docx 需要同时补充正文。求职偏好可选，具体这轮做什么以对话为准。
2. 打开应用专属 CloakBrowser，本人登录 BOSS 并完成验证码或实名；不接管日常浏览器，不绕过风控。
3. 在对话中直接说任务，例如「在深圳找AI开发20个、后端10个，月薪区间上限达到25K，找到就投」。入选一个就执行一个，完成当前岗位的联系与招呼后才读下一个JD，不等整批搜索结束。条件完整即开始，**这句话就是本轮投递授权，不再弹确认卡**。不确定的条件会在对话里询问；开始类动作必须引用你最新消息的开始意图；说“继续”“再投147个”时可沿用上一轮城市、方向、薪资和筛选条件，应用会复述本轮条件，不要求你每次重新填写。“不要猎头/中介/外包”等明确限制会带入岗位判断。
4. 想先看结果，可说「先找岗位存草稿，不要投」。之后说「投吧」执行已保存草稿。对话显示方向进度和最终结果，投递记录保留岗位与各步骤状态；开始投递后可暂停，未知结果不会重试。

薪资按**岗位月薪区间上限达到阈值即可**筛选：说“上限到20K就行”，15-25K、15-20K都满足，10-18K不满足，13薪等年终后缀不抬高月薪。低于阈值的卡片、日薪和时薪会在读JD前排除；明确“元/月”换算成K比较。面议等未知格式照常读JD核实，不直接判合格。明确说“薪资不限”才不设阈值。结果按方向显示卡片预筛排除数，它不占详情读取预算。

每个方向按自己的数量筛选，**配额按入选计**，送达、跳过、失败、未确认和待执行分别报告；跳过的岗位不补凑配额。每个方向有自己的读取预算，未用余额可顺延，前面的方向不能用掉后面方向的份额。结果会列出各方向读了多少、入选多少、为何停止，以及城市不符、薪资不足、外包/猎头/中介、方向不符、用户明确条件等拒绝分类数量，便于调整条件。采用宽松筛选：只看城市、月薪上限、明确排除的外包/猎头/中介和岗位方向大类。JD中的年限、学历、技术栈和加分项不作为拒绝理由，除非你明确要求；城市、薪资和排除条件不放宽。

「只找不投」不联系任何人：单项读取失败重试一次后跳过，安全验证、用户停止或站点异常提前结束时，已经正常完成判定的入选岗位仍保存为草稿，并说明中断原因；之后可另行说“投吧”执行。当前尚未完成的判定不会计入，模型判定失败则不保存本轮草稿，原批次保持不变。「找到就投」已经执行的内容不会撤回，遇到异常会暂停同一批次并保留真实结果。停止按钮同时停止继续找岗，并在当前执行步骤结束后暂停；之后说「继续/投吧」只处理已入选的待做步骤，不重试未确认结果。尚未搜索的剩余配额需要另发任务。

发现阶段每次搜索、翻页或打开JD前随机等待3–6秒，重试也等待；停止可立即打断这段等待。结果中会说明读取节奏。这只是降低访问频率，不能保证不触发安全验证，验证码仍须本人处理。

每天最多打开300个岗位详情页，按北京时间自然日计数；读JD、执行前重新打开岗位页、失败后的重新打开都计入，同页复用不重复计。用尽即停止并提示“今日浏览上限已到，明天继续”，已选草稿或已执行记录保留，不继续联系。这个数是本应用主动访问的保护上限，不是平台承诺；手动浏览和站点内部请求不在计数范围。遇到安全验证或访问限制页立即停止，不重试。

每日联系上限150，今日使用量按北京时间（Asia/Shanghai）自然日从账本计算，不随电脑时区改变。立即投递的新任务不能超过剩余额度，每个实际联系动作前还会复核；只找不投不占额度，发送草稿时再核对；用尽即暂停，待执行目标保留。此额度不保证平台实际仍允许联系。

### 方向调研与求职建议

在对话中说「调研一下深圳适合我的方向」，AI 会提出5–10个与经历相关的方向，程序抽样读取实际JD，逐方向展示匹配程度、理由、短板和岗位卡薪资概括。这是有限样本，不代表全站行情；结果逐方向保存并按匹配度排序，停止或失败时保留已完成部分。调研不联系HR，也不替换投递草稿。

也可以直接询问求职建议。顾问基于简历、偏好、调研结果、投递概况、最近任务的计划与结果和最近对话回答；概况区分已联系、已送达和未确认，公司名单仅涵盖当前批次且可能截断。每条对话最多2000字，保留最近50条，可手动清空；任务失败或服务重启中断会说明原因。

不同调研、发现、投递和对话任务不能并行；找到就投在同一任务内串行找岗和执行。任务进行中先停止或等结束，再修改资料或开始另一任务。不提供定时投递。

### 本地简历 ≠ BOSS 附件简历

上传到本应用的文件只用于匹配岗位，不会自动上传到 BOSS。本应用只联系 HR 和发送招呼，不发附件简历；BOSS 要双方沟通后才能发附件，请本人在站点发送。

### 状态与防重

- 「立即沟通」可能触发站点自动招呼，**也必须批准后才能点**。
- 打开会话、发送招呼分别记录，不把打开会话称作已投简历。
- 已联系过或结果未确认的岗位不会再次联系。
- 每个外部步骤先记账，再操作；崩溃时进行中的步骤重启后变为「未确认」，不自动重试。
- 成功保存具体要求/简历/固定招呼，或移除岗位，会使旧批准失效；仅选择文件、编辑尚未保存的内容或保存失败不会改变批准。执行中禁止保存；发现及正在停止期间也禁止保存。
- 固定招呼只能在个人信息页统一修改；保存会同步更新当前未发送目标，已送达或发送结果未确认的历史文本不改。站点已出现自动招呼等本方消息时仍跳过，不再补发固定文本。
- 联系完成时，将已核实的岗位、招聘者身份与联系账本同事务保存。重启后，先只读核对当前会话，再继续尚未开始的招呼步骤，不重复联系。
- 读取阶段若会话已切换，会按岗位与招聘者身份重新只读进入目标已有会话；填写后身份或历史证明变化则停止，不提交。旧记录若缺少已核实身份，会提示本人核对并手动完成，不重新联系。
- 「继续沟通」不等于已发招呼：已有会话只读核对，发现本方消息就跳过；完整历史证明没有本方消息且本批已获批准，才发送招呼。账本中已有联系或未知记录的岗位仍直接跳过。
- 页面结构、当前会话对象或发送结果无法核实时停止，不猜测成功；「未确认」步骤仍然不自动重试。
- 草案版本跨批次递增，旧页面的批准不能授权新批次。

## 数据与配置

数据只保存在本机，不进入 Git：

| 系统 | 默认目录 |
|---|---|
| macOS | `~/Library/Application Support/boss-toudi-assistant` |
| Windows | `%APPDATA%\boss-toudi-assistant` |

个人信息页的求职偏好是可选背景；本轮任务以最新对话授权为准，不另存一套可编辑计划。旧版资料/分散条件入口删除，简历原始字节、匹配正文与联系账本保留，旧条件的批准失效。

具体要求、简历原始字节/正文、固定招呼、发现及调研状态、调研结果、最近任务摘要、最近对话、每日岗位页计数与联系账本统一存于本机 SQLite，原始简历不另存散文件，因此可以在同一事务中保存或删除。旧版磁盘简历先校验并迁入数据库，再清理旧文件；清理失败会明确阻止启动，保留恢复标记，下次启动重试，不丢原始字节。

数据目录还包含专属浏览器登录态和独立 Codex 登录。**不要提交、上传或分享这个目录**。模型匹配需要将具体要求、已保存的简历正文、岗位 JD 发送给用户登录的 Codex 服务，本地存储不等于离线推理。

可选环境变量：`PORT` 更改端口；`BOSS_DATA_DIR` 指定数据目录。不要把数据目录设置在仓库内。CloakBrowser 二进制缓存独立放在 `~/.boss-toudi-assistant/cloakbrowser`，多个独立 profile 共用只读二进制；也可只读使用 `~/.cloakbrowser` 中相应免费旧版的官方二进制，但不读取那里的 key、配置或个人 profile。

服务仅监听回环地址，检查 Host、Origin、浏览器请求来源与专用请求头，不提供跨域访问。它不防御本机同一用户权限下的恶意程序。


测试包含真实 Codex app-server 进程连接本地假模型、真实 CloakBrowser + agent-browser 在本地页完成快照、填入、点击并核实实际可执行路径、HTTP 安全边界、原子保存及真实数据库/文件失败恢复、持久计时、批准失效、暂停与崩溃去重；**不消耗真实模型额度，不联系任何 HR**。

macOS 与 Windows x64 的 Node 24.11.0 / 24 LTS CI 均已通过，包括官方下载安装、真实 Codex 进程与 CloakBrowser 操作；本机 macOS arm64 + Node 26.9.0 也通过。仓库所有者需先审阅许可并把仓库变量 `CLOAK_BINARY_LICENSE_ACCEPTED` 设置为 `1.3`，CI 才能下载官方二进制；未确认则失败，不跳过冒烟假装通过。CI 也不替代 Windows 用户桌面登录测试。

真实 BOSS 只读访问遇到安全验证，未由代理完成验证。登录后的岗位/聊天 DOM、真实模型调用、真实发送均待本人登录及明确授权测试目标后验收。

## Codex 接入与许可

通过本地 Codex CLI 启动 stdio app-server；[官方选型指南](https://developers.openai.com/codex/sdk) 推荐它用于带登录、审批与事件流的自定义客户端，`codex exec` / TypeScript SDK 更适合脚本及 CI。固定使用 `@openai/codex@0.163.0` 的 app-server，属于官方标注的 experimental 接口；不承诺长期兼容或官方生产支持。顾问只获得回复、按最新消息授权选择调研/投递/执行草稿的受限工具；其他模型回合仅提出方向、评估样本或判定当前批JD。搜索和读取由程序驱动，外部写操作只由执行器处理。命令、文件修改、权限申请等模型审批请求全部拒绝。

[官方 app-server 文档](https://developers.openai.com/codex/app-server) 写明 “The app-server command and WebSocket transport are experimental and aren't supported for production workloads.” 认证章节还写明已有 local/open-source 应用可继续使用，推荐迁移到 Sign in with ChatGPT，并明确 “App-server authentication has never been permitted for commercial or hosted services.” 这些是上游原文约束，不构成本项目对具体商业场景的法律判断。ChatGPT 登录不是通用 API key，不承诺套餐额度与模型可用性。

本项目源代码 MIT。Codex 和 agent-browser 各自为 Apache-2.0；CloakBrowser wrapper 为 MIT、二进制遵守上述单独条款。依赖许可不会因本项目采用 MIT 而改变。

开发接口与模块索引见 [AGENTS.md](AGENTS.md)。

新增依赖的理由：agent-browser 不提供 CloakBrowser 二进制、官方签名校验与指纹参数；标准库也没有厂商的版本/校验协议。复用官方 wrapper 及其 tar 依赖，不另引 Playwright/Puppeteer，不自写二进制下载器。
